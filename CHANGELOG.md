# Changelog

Rolling, human-readable history of notable changes, newest first. Lets any AI session (or person)
pick up context without the old conversation. Full detail is in `git log`. See `AGENTS.md` for the rule.

## 2026-11-02
- **Toy Diorama redesign, first pieces in the game (v0.4)** (owner approved designs E/F/G): new design system and shell (drawn icons, no emoji), clickable isometric walled village built from building sprites by level (empty plots, scaffolding, panel, queue, Mags tips), 2.5D isometric world map with 6 village growth stages, ruins, allegiance banners and marching markers, chieftain portraits (sign-up picker, change dialog, portraits in header/tribe/chat; server stores choice; map shows abandoned villages' current size). Designs H–K (units, tutorial, panels+reports, terrain+armies) drawn and waiting for approval on the canvas. Preview republished single-file (art inlined; fonts from Google). Engine 160, server 120 tests.
- **Preview updated for warfare** (owner, 2026-11-02): bots hold Pathfinders, scout abandoned villages, attack the human's bot tribe-mates (tribe alerts + support to try) and rarely raid the human after protection; v0.2 saves load in the new build. Owner chose art style **D · Toy Diorama**; village view, map growth stages and chieftain portraits being designed (`docs/ART_DIRECTION.md`). Playable preview: https://claude.ai/artifact/EkSiAxXuuTvVTLpLJyEuyv (private).
- **Tribe warfare (v0.3)** (owner, 2026-11-02): new scout unit Pathfinder and scouting missions (stealthy; intel report on success; defenders with Pathfinders catch or spot them); support troops to tribe-mates and allies that stay and defend until recalled or sent back (owner keeps paying food; losses shared per contingent; supporter gets the battle report); tribe-wide incoming-attack alerts with "Send support"; mission selector on the map; reports for scouts/support. Old saves upgrade in place (missing unit keys, rebuilt movements/reports tables). Engine 160 tests, server 115 tests, web JS 107 kB gzip. Also fixed the page scrolling under the tab bar (`.main` positioning). (`0b73fc2`)
- **Single-file playable preview** (lead, 2026-11-02): `npm run build:preview` writes `apps/preview/dist/index.html` (and `artifact.html`, the same app as a fragment for sandboxed page hosts) — one self-contained file, no server, no network. The real server code (Store, GameService, TribeService, AuthService, the route modules) runs in the page on sql.js (pure-JS asm build, no WebAssembly) behind a fake Fastify router and a `window.fetch` shim for `/api/*`; `apps/web` runs unchanged. Fast small world (radius 30, speed 25), 8 computer players in 3 tribes (accept applications and diplomacy, welcome newcomers, raid abandoned villages), a starter pack for new villages, save in IndexedDB/localStorage, "Preview" pill with Reset world. Nothing under `apps/server` or `apps/web` changed. `npm run dev:preview` for hot reload. (`0c04bf8`, `fa362b5`, `da30826`)
- **Renamed to Clanfire** (owner, 2026-11-02): "TribeWars" was too close to "Tribal Wars". UI title, docs, packages (`@clanfire/*`), default database file (`clanfire.sqlite`). GitHub repo name unchanged for now.
- **Tribes (v0.2)** (owner, 2026-11-02): found a tribe (Town Hall 3; name + tag), recruit by open join / application / invitation, roles (leader, officers, members) with permissions, kick/promote/transfer/leave/disband; diplomacy — alliances and non-aggression pacts (both sides agree, cancelling gives 24 h notice so no surprise backstabs) and enemy declarations; attacks on your tribe, allies and NAP partners are blocked at send and called off on arrival if a pact formed meanwhile; tribe ranking/search, public tribe pages, tribe chat, event log; map colours by relation with tribe tags and a legend. Engine `tribes.ts` + contract in `api.ts`; server 8 new tables (in-place upgrade), 67 server + 101 engine tests; web Tribe tab (JS 102 kB gzip, +12 kB). Owner direction recorded in `AGENTS.md`: same genre as Tribal Wars but original and better — never copy. (`59d9210`)
- **First playable version (v0.1)** (owner, 2026-11-02): own village at a random spot on a 201×201 world map; wood/food/iron/gold with live counters, storage caps and food upkeep for troops; 10 buildings with upgrade queue; 5 unit types trained in Barracks/Stables; send troops to any coordinates with travel time by distance; battles with luck, wall and loot; ~800 abandoned villages that grow and refill their defenders over time (and slowly mine gold); battle reports; beginner protection. Pure rules engine shared by server and client (`packages/engine`, 83 tests), Fastify + SQLite server (`apps/server`, 35 tests; scrypt passwords, hashed session tokens, cross-site POST block, rate-limited sign-in), mobile-first React client with drag/pinch map (`apps/web`, 91 kB gzip JS). Also: `CLAUDE.md`/`AGENTS.md`, `docs/AI-WORKFLOW.md` (main session orchestrates; haiku/sonnet agents in `.claude/agents/`), `docs/HANDOFF.md`, `docs/GAME_DESIGN.md`, `docs/STANDARDS.md`. (`d74db30`)
