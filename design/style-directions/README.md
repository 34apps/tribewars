owner): https://claude.ai/artifact/MBeYhuGXimx6ASUkUGGQDB — plan and rules in `docs/ART_DIRECTION.md`.

- `artboards/` — the canvas source: one `.dc.html` per artboard (inline SVG art, Design-canvas format)

  building the real UI.
- `renders/` — WebP snapshots of every artboard (phone village, desktop village, characters, map) for
  quick viewing.
- `ART-BRIEF.md` — the shared brief the four directions were drawn from.
